## 📑 الأقسام الـ 22 المنفذة بالكامل (وفق الـ Brief)

1. `01 — NAVBAR`: شعار المحتوى الطبي + روابط التنقل السلس + زر اشترك الآن + قائمة موبايل تفاعلية.
2. `02 — OFFER BAR`: شريط إعلان علوي ثابت مع عداد تنازلي حقيقي (Live Countdown Timer).
3. `03 — HERO`: العنوان الرئيسي + القيمة المقترحة + مسار التدفق التسلسلي + زر الإجراء + إطار صورة القوس (Arch Placeholder).
4. `04 — المشكلة`: التحديات الـ 8 الشائعة في كتابة المحتوى الطبي.
5. `05 — التحول`: مقارنة بصرية واضحة بين "قبل الكورس ❌" و "بعد الكورس ✓".
6. `06 — لمن هذا الكورس؟`: تقسيم الفئات (Marketing & Content Professionals vs Medical Sector).
7. `07 — ماذا ستتعلم؟`: **Interactive Accordion** مقسم للأجزاء الأربعة مع التطبيقات والمشاريع العملية.
8. `08 — التحديث الجديد`: بطاقات تفاعلية للـ 10 محاور الجديدة ومخرجات كل محور.
9. `09 — الخريطة الكبيرة للكورس`: مسار بصري رأسي (Visual Journey Roadmap) لخطوات المنظومة الـ 13.
10. `10 — مخرجات الكورس`: حقيبة الأدوات العملية المكدسة (23 ملف وقالب ومخطط).
11. `11 — ليه الكورس مختلف؟`: مقارنة تفكير البوستات المجردة مقابل منظومة البيزنس والتحويل.
12. `12 — التدريب المجاني vs الكورس`: بطاقتا مقارنة لتوضيح الفارق والقيمة المضافة.
13. `13 — AI في الكورس`: دياجرام مسار عمل الذكاء الاصطناعي (Context → Brief → AI → Human Review).
14. `14 — المحاضر`: السيرة الذاتية لـ محمد العدوي، الإحصائيات، والخبرات، وإطار الصورة المقوس.
15. `15 — سابقة الأعمال`: نظام **Tabs** تفاعلي لدراسات الحالة (Medical, Services, E-commerce, Personal Brands).
16. `16 — Testimonials`: 3 شاشات فيديو مسجلة + سلايدر تفاعلي للمراجعات المكتوبة.
17. `17 — العرض والسعر`: بطاقة السعر المعتمد (2,000 ج.م) مع تفاصيل الباقة وضمانات الشراء.
18. `18 — الضمان`: بطاقة ضمان استرداد 100% خلال 7 أيام مع رموز الأمان.
19. `19 — FAQ`: أكورديون تفاعلي يجيب على الأسئلة الـ 12 الشائعة.
20. `20 — FINAL CTA`: بانر عريض بلون التيراكوتا وزخرفة الجيريه لمضاعفة معدل التحويل.
21. `21 — FOOTER`: الروابط السريعة، بيانات التواصل، قنوات السوشيال، وحقوق الملكية.
22. `22 — Floating WhatsApp`: زر واتساب عائم أسفل الصفحة مع تأثير نبض وفقاعة تنبيه.

## 🛠️ التشغيل والنشر (Run & Deploy)

### 1. التشغيل محلياً:
```bash
npm run dev
```
افتح المتصفح على: `http://localhost:3000`

### 2. البناء للإنتاج (Production Build):
```bash
npm run build
npm run start
```

### 3. الرفع على Vercel:
المشروع جاهز 100% للرفع على **Vercel** بضغطة زر واحدة بدون أي إعدادات إضافية.
```bash
npx vercel
```
